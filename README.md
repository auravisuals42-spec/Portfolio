### Our Core Philosophies

4. **Continuous Innovation**: We stay curious, exploring cutting-edge WebGL, custom GLSL shaders, 3D spatial UI, and modern frontend frameworks.

## 🚀 Getting Started

If you are cloning or inspecting this repository locally:

### 1. Installation
```bash
git clone https://github.com/auravisuals42-spec/portfolio.git
cd portfolio
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```
